# 관리자 시간표 사용 안내

부원 관리 화면 위쪽의 **주간 당번 시간표**는 요일(월~금)과 시간대(점심 전·점심 후·저녁)를 한눈에 보여준다.

- 이름을 누르면 해당 학생의 편집창이 열리며, 기존 요일·시간 변경을 확인하고 저장할 수 있다.
- 같은 시간대에 학생이 여러 명이면 해당 칸에 모두 표시한다.
- 작은 화면에서 표는 가로로 스크롤할 수 있으며, 키보드 Tab으로 학생 버튼에 접근할 수 있다.
- 명단 정리에서의 졸업 처리는 1~3학년 모두 같은 용어와 동작을 사용한다. 졸업 이유나 시기를 구분하여 표시하지 않는다.
- 명단 제외는 졸업과 별개의 관리 상태이며, 기록이 삭제되는 것은 아니다.
- 주간 시간표는 현재 상태의 빠른 편집 도구다. 과거 날짜 확인은 출석관리와 `RosterHistory`가 담당한다.

## 이력 저장 방식과 주의점

`User`에는 최신 배정만 유지한다. `RosterHistory`는 최초 기준 상태와 변경 필드만 저장하므로, 부원의 요일만 변경했다면 `{"day":2}`와 같이 변경된 필드만 기록한다.

각 이벤트의 `effectiveAt`은 현재 **관리자가 실제 저장한 시각**이다. 다음 주부터 적용할 배정을 미리 예약하거나 기간별로 편집하는 기능은 아직 구현되지 않았다. 이력 시작 이전의 정확한 배정도 복원할 수 없다.

`RosterAudit.gs`는 현재 명단과 과거 이벤트를 비교하는 읽기 전용 점검 기능을 제공한다. 두 시트의 쓰기는 완전한 트랜잭션이 아니므로 복구 오류가 발생하면 관리자가 원본을 백업하고 이력을 확인해야 한다.

## 다음 설계 후보: 시행일이 있는 시간표 변경

시간표 변경에 대해 별도의 **적용 시작일(`effectiveFrom`)**을 받도록 확장하면, 오늘 다음 주의 당번을 예약해도 이번 주 기록이 변경되지 않는다. 현재는 해당 기능이 없으므로, 운영에서는 실제 적용 시점에 변경하거나 사전에 검증된 별도 절차를 마련해야 한다.

이 문서와 변경 코드는 개발 브랜치 전용이며 운영용 `main`이나 Apps Script 배포본을 변경하지 않는다.

## 달력에서 출석 면제 일정 설정

관리자 로그인 후 **달력 → 등교·시험 일정**에서 지정한다. 해당 일정은 날짜 범위만 저장하며, 해당 기간의 날짜마다 같은 기록을 복제하지 않는다.

- **공휴일·재량휴업일·연휴·방학:** `휴업·방학·공휴일`을 선택하고 시작일과 종료일을 입력한다. 양끝 날짜 모두 정규 당번 출석 의무가 없다.
- **시험:** `시험`을 선택하고 시험 첫날과 마지막 날을 입력한다. **시험 첫날 14일 전부터 마지막 날까지** 정규 당번 출석 의무가 없다. 시험이 하루라면 시작일과 종료일을 같게 설정한다.
- **수정:** 기존 항목에서 `수정`을 누른다. 이전 내용은 이력에 남고 새 버전이 적용된다.
- **해제:** 면제 일정이 잘못 등록됐다면 `해제`를 누른다. 기존 기록을 지우는 대신 취소 버전을 추가한다.

현재 NEIS 학사일정 기반의 자동 결석 면제도 유지한다. 수동 등록된 면제 일정은 NEIS 조회가 실패하더라도 정규 결석을 생성하지 않도록 우선 적용된다.

### 이미 결석 처리된 경우

과거 날짜에 면제 일정을 뒤늦게 추가하면 기존 `absent` 기록은 자동 삭제하지 않는다. 관리자 **출석 관리 → 해당 날짜**에서 `면제 정정 필요`로 표시되는 학생을 확인한 뒤, `면제 정정`을 눌러야 한다.

정정하면 기존 출석 기록의 ID·날짜·시간대는 유지되고 `excused` 상태로 바뀐다. 별도의 `AttendanceCorrections` 시트에 원래 결석 ID, 사유, 정정 시각을 기록하고 학생의 누적 결석 횟수를 한 번 줄인다. 중복 정정은 거절한다.

주의: Google Sheets는 여러 탭을 원자적으로 갱신하지 않는다. 기록 정정·횟수 갱신 중 실패하면 원본 데이터를 백업한 뒤 이력과 숫자를 대조해야 한다. 사후 수정이 모든 기존 기록을 자동으로 재계산한다는 의미는 아니다.

## 학생 화면: 시간대별 당번 열람

메인 출석 화면에서 **‹ / ›**를 누르면 같은 날의 점심 전·점심 후·저녁 담당자를 살펴볼 수 있다. **현재 시간대에만 출석 버튼이 나타나며** 다른 시간대는 열람 전용이다. 서버 역시 현재 시각과 당번 배정을 다시 검증한다.

현재 출석 시간대가 있는 상태에서 다른 시간대를 열람하면 작은 **현재 당번으로** 버튼이 나타난다. 시험·휴업일에는 면제 안내를 표시한다. 단순한 농구 경기 등 일정은 자동 면제에 영향을 주지 않는다.

## 성능

`RosterHistory`는 최초 기준 상태와 변경 필드만 저장한다. 월간 달력은 이력을 한 번 정렬한 후 날짜 순으로 적용하며, 42개 날짜를 만들 때 매일 전체 이력을 반복 재생하지 않는다. 이후 규모가 더 커지면 월별 스냅샷 캐시를 추가할 수 있지만 현재는 데이터가 작으므로 불필요한 캐시 복잡성을 피한다.
