# 도서부 출석체크

> **15기 김우준 개발 브랜치 안내:** 이 브랜치는 학교 운영용이 아닙니다. 관리자 서버 인증을 포함하므로 테스트용 Apps Script와 독립된 시트를 사용하세요. 설정과 테스트 방법은 [관리자 인증 안내](docs/ADMIN_SETUP.md), 위험 및 향후 작업은 [개발 감사](docs/DEVELOPMENT_AUDIT.md)를 확인하세요. `WhoSia`의 변경은 안준표의 운영용 `main`에 자동 반영되지 않습니다.


Google Apps Script 웹앱입니다. 화면(`Index.html`), 서버 로직(`Code.gs`), DB(구글 시트)가 모두 구글에서 돌아갑니다.

## 개발 브랜치 주요 변경

- 학생 출석·보충은 도서관 컴퓨터에서 종전처럼 처리하며 별도 학생 로그인은 없다.
- 관리자 화면만 비밀번호 로그인으로 보호하고, 관리자 페이지에서는 15분 동안 사용하지 않으면 자동 로그아웃한다.
- `RosterHistory` 시트에 [시간표 변경 이력](docs/TEMPORAL_ROSTER.md)을 최초 기준 상태 + 변경분 형태로 저장한다. 날짜별 전체 시간표 복사본을 생성하지 않는다.
- 과거 시간대의 담당자와 학년을 이벤트 이력에서 복원한다. 마이그레이션 이전 정보는 **미확인**으로 표시한다.
- 부원 명단에서 제외할 때도 과거 시간표를 보존한다.
- 운영용 `main` 또는 실제 Apps Script 배포와는 별개이며, 개발용 시트에서 마이그레이션과 테스트를 확인해야 한다.

## 처음 설정

1. `clasp push -f`로 올립니다. (`.clasp.json`의 `scriptId`는 직접 만들어야 합니다: `clasp create` 또는 `clasp clone <scriptId>`)
2. 스크립트 속성에 `NEIS_KEY`(NEIS 인증키)를 추가합니다.
3. 편집기에서 `setup_`(시트·트리거 생성), `findSchool_`(학교 코드 저장)을 한 번씩 실행합니다.
4. 배포 → 웹 앱(실행 계정: 나, 액세스: 모든 사용자)으로 배포합니다. 코드를 고친 뒤에는 배포 관리에서 새 버전으로 올려야 반영됩니다.

## 규칙

- 당번: 점심 전 12:30~13:00, 점심 후 13:00~13:20, 저녁 18:00~18:20 (마감 시각에 미출석이면 결석)
- 결석 면제(NEIS 학사일정 기준): 휴업일·공휴일, 정기시험 2주 전~시험 마지막 날, 해외체험학습·졸업식·종업식·진로탐색활동·이공계 대학탐방(해당 학년). 규칙은 `Code.gs`의 `EXEMPT_EVENT_WORDS` 등에 있습니다.
- 학년·졸업: **자동 진급하지 않습니다.** 관리자가 3월 1일 이후 부원 관리의 **학년도 진급**에서 대상 명단을 미리 확인하고 확정하면, 이전 1·2학년은 2·3학년으로 바뀌고 기존 3학년은 졸업생(`type` 0)이 됩니다. 신입생은 부원 추가에서 등록하고 조기졸업은 개별적으로 처리합니다.
- 명단 제외는 출석 기록이 없는 부원을 대상으로 하며 과거 시간표는 보존합니다. 제외된 부원은 관리자 화면의 **명단에서 제외된 부원**에서 복귀시킬 수 있습니다. 졸업생과 명단 제외는 구분됩니다.
- 부원 추가·수정은 저장 전에 이름·학년·요일·시간을 확인합니다. [진급 운영 안내](docs/ADMIN_SETUP.md)를 참조하세요.
